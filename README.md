# A little invitation 🌻

A lightweight, responsive invitation page built with HTML, CSS, and vanilla JavaScript. It has no build step or backend and is ready for GitHub Pages.

## Run locally

Open `index.html` in a browser. Google Fonts are optional; the page falls back to system serif and sans-serif fonts if the fonts cannot load.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html`, `css/`, `js/`, and `README.md` to the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose your default branch and the `/(root)` folder, then save.
4. After GitHub Pages finishes publishing, open the URL shown in the Pages settings.

All project asset paths are relative, so the site works as a repository site as well as a custom domain.
